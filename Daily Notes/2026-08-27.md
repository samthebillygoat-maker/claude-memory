## Caporales — Order Tablet Recommendation (FINAL)

### Placement (confirmed 2026-08-27)
- Front of house, **at/near the register** — not in the kitchen line. No grill heat, no fryer grease, no steam.
- Plugged in 24/7.

### Decision
- **iPad 11th gen (A16)** on a **locking counter stand**. ~$449 new; ~$330–380 used/refurb.
- Buy the A16 specifically, **not the 10th gen** — the 11th gen is the cheapest iPad with the built-in **80% Charge Limit** (Settings → Battery → Battery Health). That single toggle solves the always-plugged-in battery-wear problem.
- At room temperature with the 80% cap on, expect **4–5 years**, not a 2-year consumable. (The 2-year figure only applies to hot kitchen-line placement.)

### Rejected options
- **Mini PC + 24" monitor** — cheaper (~$280) and battery-free, but it's cable spaghetti on a customer-facing counter. Would have been the pick for a back-of-house wall mount.
- **iPad 10th gen / cheap refurb** — no charge-limit toggle.
- **Amazon Fire HD 10** ($139 w/ ads, $155 without) — rejected. No charge-limit setting (fatal for 24/7 plugged-in), lockscreen ads on a customer-facing counter, Fire OS 8 with no Google Play (sideloading breaks on updates), no built-in kiosk lock (needs Fully Kiosk ~$10). Silk is Chromium so the web app itself would load fine. A used iPad 9th/10th gen is $130–180 — same money, better device. OK as a spare or menu display only.
- **Galaxy Tab A9+** (~$134–220) — fine as a spare. Samsung's "Protect battery" caps at 85%, but Samsung says availability varies by model, so verify on the actual unit. Cheap Android also kills background browser tabs aggressively = missed orders.

### Printer — DECIDED AGAINST (owner's call, 2026-08-27)
- Owner does not want a receipt printer. Register staff relays orders to the kitchen verbally. Reasonable for a small taqueria.
- Saves ~$375. **New total: ~$430–550** (iPad + locking stand).
- Consequence: the tablet is now the **single point of failure** — it is the only place an order appears. This raises the bar on the tablet, so the iPad A16 pick stands; do not downgrade to save money.

### Replacing what the printer would have done
1. **SMS/email alert to the owner's phone on every new order.** Free, and the only backup if the tablet sleeps, drops Wi-Fi, or the tab dies silently. Vercel prod env already has `OWNER_EMAIL` set — email alerts may be a small add.
2. **Verify the owner panel auto-refreshes** (polling or SSE). If it needs a manual reload to surface new orders, a tab opened at 11am shows nothing at 7pm and nobody notices. This is now the top risk — a code question in the caporales repo, not a hardware one.
3. **Test that the alert sound still fires after the tab has been open all day.** Browsers throttle audio on long-lived tabs.

### REVISED — budget path chosen (owner found $80 / 3GB tablet)
- Owner is going with an **$80, 3GB RAM tablet** instead of the iPad. Viable, given the changes below.
- **Buy two ($160).** With no printer, a spare on the shelf buys more reliability than better hardware does. This is the key move.
- 3GB RAM is fine for a single browser tab — the Next.js order panel is not heavy. RAM is not the risk.

**Real risks and their fixes:**
- *No charge limit* → **$15 smart plug on a timer**, charge ~2 hrs/day instead of 24/7. Solves the battery-swelling problem cheaply.
- *Low-RAM Android kills background apps* → uninstall/disable everything else so nothing competes for the 3GB; turn off battery optimization for the browser.
- *Screen and Wi-Fi sleep* → display always-on, Wi-Fi set to never sleep.
- *No kiosk lock* → Fully Kiosk (~$10) or built-in screen pinning.

**Non-negotiable:** SMS/email order alert to the owner's phone. With no printer and budget hardware, the phone is the actual reliability layer; the tablet is a convenience screen. This is what makes $80 rational rather than risky.

- Expect to replace around year 2. At $80 each, acceptable.

### Device chosen: Walmart onn. 10.1" — $80 (confirmed on shelf 2026-08-27)
Box specs: Android 14 · 10.1" 1280×800 IPS · 2 GHz octa-core · 3 GB RAM · 32 GB + microSD · USB-C · 17 hr battery · Google Play Protect / Kids Space · 1 yr warranty · distributed by Walmart Inc.

**Why this beats the Fire HD 10:** real Android 14 **with Google Play** (not Fire OS). Means real Chrome, working web notifications, Fully Kiosk available from the Play Store, no lockscreen ads. That was the whole objection to the Fire. And it's cheaper.

**Check before buying:**
- 1280×800 on 10.1" is low res (~149 ppi) — text will be soft. Load the order panel on a display unit and confirm it reads cleanly; bump browser zoom if needed.
- Dim panel (~300 nits). If the register counter gets daylight, verify readability at max brightness.

**Setup steps for this device:**
1. Install **Chrome** from Play Store — do not use the stock browser.
2. Settings → About → tap Build number 7× → Developer options → **Stay awake while charging**.
3. Settings → Apps → Chrome → Battery → **Unrestricted**.
4. Uninstall/disable Kids Space and preloaded bloat so nothing competes for the 3 GB.
5. Screen pinning (Settings → Security) or Fully Kiosk (~$10).
6. **$15 smart plug on a timer** — no charge limit on this device and it runs plugged in 24/7.

### Setup checklist
- Locking/secure counter stand (~$30–50 budget, or $50–100 Heckler/Compulocks) — front-of-house tablets walk.
- Smart plug timer (or Charge Limit 80% if on an iPad).
- Kiosk mode / screen pinning locked to the order screen.
- Screen sleep: Never.
- 5 GHz Wi-Fi; add a mesh node if the register area is a dead spot.
- Screen protector; skip the heavy silicone case (no grease at the front).
